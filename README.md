# Infografía interactiva: Cómo consultar las calificaciones en EducaMadrid

Este proyecto recoge un recurso didáctico interactivo diseñado para ayudar al alumnado a:

- Acceder al apartado de Calificaciones en el Aula Virtual.
- Interpretar la información del calificador.
- Distinguir tareas presentadas, no presentadas y calificadas.
- Consultar comentarios y retroalimentación del profesorado.
- Utilizar las calificaciones como herramienta de mejora.
